# Extended Custom Tab

Chrome-расширение, заменяющее стандартную стартовую страницу новой вкладки.

## Отличия от стандартной new-tab

| Стандартная new-tab | Extended Custom Tab |
|---|---|
| Максимум 10 ярлыков | Без ограничений |
| При малом числе ярлыки прижаты к левому краю | Строка всегда по центру |
| Добавление ярлыка только через кнопку | Можно перетащить закладку/ссылку прямо на страницу |
| Фон задаётся темой Chrome | Любая своя картинка (drag&drop или через меню) |
| Иконки через сервис Google | Те же иконки, что в панели закладок (Chrome `_favicon` API) |
| Нельзя переставлять ярлыки внутри | Drag&drop перестановка |

## Возможности

- **Безлимитные ярлыки** с фавиконками (тянутся из внутреннего кеша Chrome, тот же источник что для закладок)
- **Drag-and-drop**:
  - Перестановка ярлыков мышью
  - Перетащить закладку/вкладку/ссылку → добавится новый ярлык (на конкретный ярлык — вставится в эту позицию, в пустое место — добавится в конец)
- **Кастомный фон**: загрузка из файла (ресайз до 2560px, JPEG q=0.85, хранится в `chrome.storage.local` как data URL). Сверху лёгкий градиент чтобы текст читался на любом фото.
- **Меню настроек**: шестерёнка ⚙ в правом нижнем углу (сменить/убрать фон)
- **Заметки**: панель в левом верхнем углу. Создание/удаление/чекбокс с зачёркиванием. Хранятся в `chrome.storage.sync` — синхронизируются между Chrome на разных устройствах через тот же Google-аккаунт, в который ты залогинен в браузере.
- **Календарь**: панель в правом верхнем углу. Месячная сетка с выделением сегодня, навигацией по месяцам и кликом по дню для просмотра событий. Работает сразу без настройки. Опционально подключается iCal-фид Google Calendar — на днях с событиями появляются точки, в выбранный день показывается список.
- **Почта**: панель под календарём. Список последних непрочитанных писем из Gmail (отправитель, тема, превью, время). Источник — встроенный Atom-фид Gmail (`mail.google.com/mail/feed/atom`), использует сессию браузера (нужно быть залогиненным в Gmail в этом профиле Chrome). Без OAuth, без настройки. Лимит 20 непрочитанных, только inbox. Клик по письму открывает его в Gmail.
- **Поиск Google** в шапке
- Хранение в `chrome.storage.local` — данные переживают перезапуск браузера

## Подключение Google Calendar (опционально)

Расширение работает с любым iCal-фидом, без OAuth и без регистрации приложений в Google Cloud.

1. Открой Google Calendar → **Settings** (шестерёнка)
2. **Settings for my calendars** → выбери календарь
3. Прокрути до **Integrate calendar** → найди **Secret address in iCal format** → скопируй ссылку
4. На новой вкладке нажми шестерёнку ⚙ в правом нижнем углу → **Подключить календарь (iCal)** → вставь ссылку
5. События подтянутся, на днях появятся точки

⚠️ Этот URL — фактически пароль к календарю. Кто угодно с ссылкой видит все события. URL хранится только в `chrome.storage.local` (локально на твоей машине), никуда не отправляется кроме самого calendar.google.com при запросе.

Поддержка: одноразовые события (`VEVENT`), all-day, время старта/конца, название, локация. Повторяющиеся события (`RRULE`) пока не раскрываются — увидишь только первое вхождение.

## Установка

1. Клонируй репозиторий или скачай ZIP
2. Открой `chrome://extensions/`
3. Включи «Режим разработчика» (правый верхний угол)
4. «Загрузить распакованное» → выбери папку с расширением
5. Открой новую вкладку

## Технические детали

- Manifest V3
- Permissions: `storage`, `favicon`
- Host permissions: `https://calendar.google.com/*`, `https://mail.google.com/*` (для iCal-фида и Atom-фида Gmail)
- Без внешних зависимостей (vanilla JS/CSS)
- Картинка фона хранится **внутри** расширения как копия — удаление исходного файла не ломает фон
- Лимит хранилища: 10 МБ (квота `chrome.storage.local`). После ресайза одна фоновая картинка обычно <500 КБ.

## Структура

```
manifest.json    — Manifest V3, переопределение newtab
newtab.html      — разметка
newtab.css       — стили (dark teal палитра)
newtab.js        — логика: storage, drag&drop, фон, меню
```
